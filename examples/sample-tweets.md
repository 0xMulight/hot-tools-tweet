# 推文示例

以下是符合规范的热门工具推文示例，供参考写作风格和结构。

## 示例 1：桌面工具

```
🖥 Media Downloader — 支持 1000+ 网站的 macOS 视频下载器

想下载 YouTube、B站、TikTok 的视频到本地但找不到好用的工具？
Media Downloader 是 macOS 上最简洁的视频下载器，
粘贴链接 → 选格式 → 一键下载，三步搞定。

安装：
  brew install media-downloader

打开后把视频链接贴进去，选 MP4 1080p，点 Download。
常见坑：B站需要先在设置里导入 cookies.txt 才能下高清。

github.com/mhogomchungu/media-downloader
收藏备用，迟早用得上。
```

## 示例 2：命令行工具

```
📊 fx — 终端里的 JSON 瑞士军刀

每次在终端里用 python -m json.tool 格式化 JSON 都嫌麻烦？
fx 让你在终端里交互式浏览 JSON，支持折叠、搜索、过滤，
还能直接用 JavaScript 表达式处理数据。

安装：
  npm install -g fx
  # 或 brew install fx

用法：
  curl https://api.example.com/data | fx
  # 按 . 键搜索，按 e 键展开全部

常见坑：Windows 终端需要 Windows Terminal，cmd 不支持。

github.com/antonmedv/fx
终端党必装。
```

## 示例 3：Web 工具

```
🎨 Excalidraw — 开源白板，画图比 Figma 快 10 倍

需要快速画架构图、流程图、或手绘风格的示意图？
Excalidraw 是开源在线白板，手绘风格天生好看，
不用学任何设计工具，打开浏览器就能画。

不用安装，直接打开 excalidraw.com 就能用。
支持导出 PNG/SVG，还能嵌入 Notion 和 Obsidian。
常见坑：免费版文件存在浏览器本地，换设备前记得导出。

github.com/excalidraw/excalidraw
做方案、写文档的时候打开就用。
```

## 结构拆解

每条推文的骨架：

1. **🔧 钩子 + 一句话定位** — 什么工具，为什么值得看
2. **💡 价值** — 解决什么问题，谁来用
3. **📖 教程** — 安装命令 + 操作步骤 + 排坑
4. **🔗 链接** — GitHub/官网 URL，独立一行
5. **💬 软 CTA** — 收藏/试用，不强行号召
